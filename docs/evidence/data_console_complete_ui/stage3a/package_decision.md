# Package Decisions

* **msw**: Approved (Stage 3B). Network-level request interception for explicit mock mode and integration tests.
* **openapi-typescript**: Approved (Stage 3B). Generates compile-time TypeScript types from the backend OpenAPI document.
* **openapi-fetch**: Added (Stage 3B). Official companion client for path-, parameter-, request-, and response-typed fetch calls.
* **@playwright/test**: Approved (Stage 3B). Route smoke and browser E2E starting with the shell.
* **@axe-core/playwright**: Added (Stage 3B). Required for automated accessibility scans.
* **@xyflow/react**: Approved (Stage 3D). Interactive graph explorer canvas. Do not install before Graph Explorer implementation.
