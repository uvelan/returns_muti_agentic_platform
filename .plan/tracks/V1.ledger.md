- Write path (recorded decision): the brief says "reuse the DocumentEditor and
  its governance-proposal write path". The **editor** is reused literally. The
  **write path** is not, and cannot be: `agentConfigApi.save` is
  `PUT /api/agents/{manifest_id}`, which resolves a manifest id, refuses a
  non-agent module with `AGENT_NOT_FOUND`, and validates through the agent
  loader. `support_template` is a field on `ReturnPlatformConfiguration`, so it
  moves the way every other behaviour field moves: `POST /api/config/releases`
  (DRAFT) → `PATCH .../domains/RETURN_PLATFORM` with `{support_template: …}`
  (which validates the *result* against the full model) → promote VALIDATED →
  promote RELEASED with the snapshot's `head_revision` as the optimistic guard.
  That is the same governed lifecycle the AI provider and task editors already
  ride, and it is what makes the case's pinned `configurationReleaseId` a real
  template version pin (contracts.md §8). Flagged here rather than silently
  substituted.
