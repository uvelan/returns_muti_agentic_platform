## Scope

### Backend
1. **Template config** — new `configuration/support_template_configuration.py` per contracts.md §8 (StrictConfigModel, constrained grammar, model validators: default_variant exists, formatter ids in the code allowlist, subject placeholders resolve). New `operations/template_formatters.py` (allowlist registry `text|date|currency|address|item_list`). `production.yaml` `support_template:` block reproducing today's `compose_support_handoff` output as the default variant + a parcel/LTL variant pair for acceptance 2 (integration agent applies the yaml + one-line field append on your branch).
2. **Renderer** — new `operations/support_template_renderer.py`: variant selection (first matching declarative selector, else default); per-source binding resolution (`case_fact:` via `latest_case_facts_scoped`; `return_record:` via the record projection; `graph:` with **batched** on-demand sync — collect all missing graph bindings, one `OnDemandSyncCoordinator.synchronize` per source, retry together; anchor `dynamic_knowledge/on_demand_sync/coordinator.py`); `fallback` after declared-binding failure; `TemplateGap{field_id, reason}` for missing required; per-field `{source, source_path, fact_id?}`; per-record section groups stamped `return_record_id`; within-draft resolution cache; `{{`/`}}` escaping.
3. **Workflow gate** — `workflows/return_case_workflow.py` + `return_case_activities.py` + `workflows/worker.py` (activity registration). Anchors: `_open_support` ~1590 (gate goes between `draft_support_request` and the send), `_await_policy_override` ~1437 (clone its shape — registered duplication, do NOT extract a shared helper), `workflow.patched` precedent ~1606, `_continued_input()` ~2146 (add `resumed_template_review_deadline_iso` + review map). Patch id `"support-template-review-gate"`. All request drafts first (grouping per `support_gate.request_grouping`, default one per case), then one map-based wait over `{request_id → review state}`; signal handlers `template_approved|template_revised|template_cancelled` + `clarification_answered` stub (delegating to a V3-owned activity name, `record_clarification_answer` — declare, don't implement) + reply signals routed to the same map for `SUPPORT_REPLY` reviews; per-case reminder cadence (DR-7) via `resolve_business_deadline`; `on_timeout` policy with gap/guard-forced hold; `HELD_FOR_OPERATIONS`/`TEMPLATE_REVIEW_GUARD_BLOCKED` at deadline; case status `AWAITING_TEMPLATE_REVIEW`. New activities: `record_template_draft`, `record_template_revision`, `rerender_template_draft`, `snapshot_sent_template` (snapshots the S2-frozen approved payload; sends via S2's `ensure_case_support_thread` + `post_support_message`; transitions the aggregate to `SENT`/`DELIVERY_FAILED`). Un-patched histories keep today's straight-through path via `compose_support_handoff` — untouched.
4. **API** — new `api/case_panel.py` + `api/case_reviews.py`: contracts.md §9 endpoints (`/panel`, `/edit-state`, `/reviews/{id}/{approve|revise|cancel}`, `/template-review/redraft`, `/reviews/{id}/recovery/{retry|abandon}`). Capabilities: `RETURNS_SUPPORT_ACT` (mutations), `RETURNS_SESSION_READ` (reads), `RETURNS_REVIEW_RECOVERY` (recovery — integration agent adds the enum member in `security/capabilities.py` on your branch); case-access check per the 404-for-other-principal pattern (anchor `dynamic_knowledge/api/order_agent.py` transcript route). Panel: compose + canonical-serialize + hash → `ETag` header; `Cache-Control: private, no-cache`, `Vary: Authorization`; absolute instants only; section-registry seam (`CasePanelView` DTO frozen — V2/V3 add sections through the registry, you never touch the contract after merge); degraded-section policy; `reviews[]` with aggregate state + recovery status; accepted-command states. Approve body carries `draft_version`, `canonical_edit_version`, payload hash — exact field names. OpenAPI export regenerated (integration agent runs `contracts:generate`).
5. **Config UI** — new `frontend/src/domains/config/SupportTemplateSection.tsx` on the existing `DocumentEditor` (anchor `domains/config/AgentsSection.tsx` — reuse its form|split|json editor and governance-proposal write path) + variant preview (calls a small preview endpoint you add beside the renderer: render against a sample case, `RETURNS_SESSION_READ`). Backend + frontend suites green. Ledger + delta report + handoff spec committed.
