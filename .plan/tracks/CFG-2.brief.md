## Scope

1. **The composer.** New `backend/src/return_platform/configuration/composition.py` exposing `compose_configuration_document(directory: Path, *, document_keys: frozenset[str]) -> ComposedDocument` (fields: `document: dict[str, Any]`, `files: tuple[Path, ...]`, `sha256: str`, `total_bytes: int`). `index.yaml` carries the document-level keys, an ordered `parts:` list of relative POSIX paths, an optional `entries:` mapping of *section → ordered list of paths*, and optionally inline sections. Every rule below raises `ValueError` with both offending file names in the message: missing `index.yaml`; a listed path that does not exist; a `*.yaml`/`*.yml` file anywhere under the directory that no list names (`"... is not listed in <dir>/index.yaml; this loader does not glob"` — mirror `backend/config/README.md`'s manifest stance, no globbing); a part root that is not a mapping; a path escaping the directory; a section declared twice (inline index sections count); an `entries` stem that collides with another under `casefold()` or fails `^[A-Za-z0-9][A-Za-z0-9_.-]*$`. An `entries` key is the file stem, used as-is (`tasks/support.message.classify.v1.yaml` → `support.message.classify.v1`). `sha256` is a framed digest over `index.yaml` then each listed file in list order (`relpath\0len\0bytes`), so it keeps today's "the bytes on disk changed" meaning, comments included.
